2026上半年AI Agent融资83起、同比+131%，下半年创投圈却一夜「速冻」：不看Agent了。璞合拆解这轮退潮——落掉的是通用Agent的宏大叙事，不是垂直Agent的生意，钱正在从「为叙事买单」转向「为现金流买单」。

📎 本文为转载导读｜素材来源：36氪（霞光AI实验室）《Agent的坠落，只用了一个夏天》。原文链接：https://36kr.com/p/3939139683112838。以下为璞合资本的导读与判断，核心数据与案例归原作者，观点为璞合独立表达。

📌 一句话速览

AI Agent 曾是 2025 下半年到 2026 上半年一级市场最热的一条赛道——烯牛数据统计，2026 上半年 AI Agent 融资 83 起、同比增幅 131%。但进入 2026 下半年，创投圈的情绪几乎是一夜之间翻转：「不看 Agent 了」「AI 应用的项目内部已经推不动了」。璞合想说的是：这轮「坠落」落掉的，是通用 Agent 的宏大叙事，而不是垂直 Agent 的真实生意——钱没有离场，只是从「为叙事买单」转向「为现金流买单」。

一、发生了什么：从「智能体元年」到「速冻」

原文给出了一条非常陡的情绪曲线。2024 年底到 2025 年，DeepSeek 和 Manus 接连点燃「智能体元年」，一批 Agent 项目在没有产品、没有收入的情况下就能拿到融资，甚至要求想出手的投资人「连投两轮」才能拿到入场券。这种热度一直延续到 2026 上半年——烯牛数据《2026 年 H1 中国私募股权市场深度解析报告》显示，AI Agent 赛道半年融资 83 起，同比增幅高达 131%。

但进入下半年，情况急转直下。原文引用一线从业者的说法，投资机构的谨慎已经变成创投圈的「集体情绪」：年轻的 Agent 创业者无论履历多漂亮，都要先过投资人的三道「天问」——用户规模是多少？付费率预计怎么增长？如果模型厂也做这个方向，你们怎么办？

这三问，本质上是把 Agent 项目从「技术叙事」拉回到「商业账本」。璞合认为，这才是这轮「坠落」最值得记的东西：不是钱变少了，而是钱的定价标准变了。

二、Agent 的商业化困境：SaaS 薄利，还是驻场吃灰？

原文对 To B Agent 的剖析，是全篇最有价值的部分。Agent 要真正接管企业增长，落地时却卡在一个两难里：

  • SaaS 模式毛利变「弹性」：Agent 每完成一轮思考执行都要消耗 Token 与推理算力，用户量越大，Agent 公司的 Token 成本越高。传统 SaaS 的 70% 毛利目标，在 Agent 上很难复制——规模效应在这里「失灵」了。
  • 收费方式被迫重构：因为不能按 Token 用量直接向客户收费，一批公司开始把 Token 和其他成本打包成新计费形式——北森的 AI HR 平台按飞书「点值」计费，主打 AI 语音外呼的云蝠智能按「通话时长」收费，LibTV 按会员积分消耗。计费方式创新，暴露的正是「Token 成本」这座绕不开的山。
  • 护城河质疑：自身没有底层模型的 To B Agent，长期面临「没有护城河」「Token 中转站」的质疑。

这段话击中的，是 Agent 赛道最真实的痛点：Agent 的边际成本不为零，甚至可能随规模上升——这和传统软件「越规模化越赚钱」的底层逻辑是相悖的。一个商业模式如果规模越大、成本越高，那它本质上不是「软件生意」，而是「服务生意」，估值模型要整个换掉。

三、垂直场景里的「真需求」依然在

但璞合不同意「Agent 凉了」的简单结论。原文自己也留了一条口子：一些垂直 Agent 产品服务的行业格局分散、中小公司居多，这些公司有提效需求、却没有预算和能力做大模型的后训练与微调——这恰恰给第三方 Agent 公司留出了市场空间。

原文举了一个很具体的例子：报关单填写，几乎是所有行业里人力最密集、最重复劳动的环节之一，人工一天填 10 个单、单条成本 1000 元左右；用 Agent 一天能填上百个、单条成本降到 6、700 元。这种「人效账」算得清的场景，付费意愿是真实存在的。

璞合把它提炼成一句话：Agent 的机会，不在「做一个通用智能体」的宏大叙事里，而在「算得清人效账」的垂直场景里。越是人力密集、重复度高、容错代价低的环节，Agent 越容易落地、越容易收费。

四、璞合观点：钱没有离场，是在重新选边

站在 FA 的视角看这篇「坠落」的文章，璞合想给三个判断：

  • 第一，退潮淘汰的是叙事，不是生意。这轮降温真正出清的，是那些「靠概念拿钱、没有真实付费」的通用 Agent 项目。它们本就不该在这个阶段拿到那个估值。而能证明留存、能证明毛利结构的垂直 Agent，反而会因为少了噪音而更被认真对待。
  • 第二，出海是 Agent 对抗国内退潮的一条出口。璞合长期看三个方向：出海、AI Agent、AI 智能硬件。这三个方向的交集，恰恰是这轮降温里最抗跌的——海外中小企业数字化程度更高、付费习惯更成熟，Agent 在海外更容易形成商业闭环。国内叙事退潮，反而会把一批务实的 Agent 创始人推向出海。
  • 第三，判断 Agent 项目值不值得投，看三个信号。一看留存——用户是不是真的离不开，而不是「装完就吃灰」；二看毛利结构——Token 成本到底能不能被订阅费覆盖、覆盖后还剩多少；三看模型依赖度——它对底层模型的可替代性有多高，模型能力跃迁时它是不是第一个被碾过去。

所以，当有人说「Agent 的坠落只用了一个夏天」时，璞合更愿意把它翻译成另一句话：Agent 的「夏天」结束了，但它的「秋天」刚开始——泡沫散去之后，剩下的才是能过冬的生意。融资是过程，交付才是结果。这句话我们说过很多次，今天再说一遍，因为它在这个时间点，格外应景。
